snplugins.pythonParser package¶

pythonParser: a plugin (see sn.plugins) that makes a model of a Python program – its packages, modules, classes, functions, methods, doc strings and imports – and a view of it, from the Tools menu’s “Python Parser…” (see dialog). It’s built on the ontology pythonOntology.snm, in this folder, whose types name the hooks (see hooks) that show a class’s or function’s code from the view.

  • parser: reads the Python files, and makes the model;

  • source: finds a class or function in its file again, as it is now;

  • hooks: the menu items, tooltips and double-clicks the ontology names;

  • dialog: the front end, and the view.

Created on Oct 10, 2026 (a plugin since Oct 17)

Code author: Rob Kremer <robkremer@me.com>

snplugins.pythonParser._dialog: Any = None¶

The dialog, while it’s open: the menu item brings it to the front rather than opening another.

snplugins.pythonParser.register(ctx)¶

Add “Python Parser…” to the Tools menu (see sn.plugins.PluginContext).

Parameters:

ctx (sn.plugins.PluginContext) – The plugin’s context.

Return type:

None
