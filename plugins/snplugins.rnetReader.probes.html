snplugins.rnetReader.probes module¶

Gaines’s probes of a KNet net, as KNet’s “Probes”, “Probe Sets” and “Reconstruct” commands give them: each probe is a way the net’s nodes can be marked – true, false or both – that its rules allow (see sn.model.clingoReasoner.ClingoReasoner.probes(), and PROBE_KINDS: consistent, admissible or compatible probes); a node’s probe sets are the probes it’s true in and those it’s false in; and the reconstruction is the links that the probe sets say hold: A includes B if B is true in every probe A is, and A false in every probe B is; A excludes B if each is false in every probe the other’s true in; and A coexcludes B if each is true in every probe the other’s false in.

  • netNodes(): the net’s nodes (its KNODE individuals that KNet reasons about);

  • findProbes(): their probes, part by part (nodes that aren’t linked have every combination of their probes: so each connected part’s are found on their own);

  • reconstruct(): the reconstruction – across the parts too;

  • report(): all three, as text, as KNet writes them;

  • ProbesDialog: shows the report, from a node’s menu (see hooks.showProbes()).

snplugins.rnetReader.probes.SYMBOLS = {'F': '−', 'T': '|', 'TF': '+'}¶

How a probe shows each node’s mark (as KNet does): −A false, |A true, +A both.

snplugins.rnetReader.probes.INCLUDES = '-->'¶

The links a reconstruction finds (see reconstruct()), as KNet writes them: A --> B (A includes B), A <-- B (B includes A), A -|- B (A excludes B), and A -||- B (A coexcludes B).

snplugins.rnetReader.probes.INCLUDED = '<--'¶

The links a reconstruction finds (see reconstruct()), as KNet writes them: A --> B (A includes B), A <-- B (B includes A), A -|- B (A excludes B), and A -||- B (A coexcludes B).

snplugins.rnetReader.probes.EXCLUDES = '-|-'¶

The links a reconstruction finds (see reconstruct()), as KNet writes them: A --> B (A includes B), A <-- B (B includes A), A -|- B (A excludes B), and A -||- B (A coexcludes B).

snplugins.rnetReader.probes.COEXCLUDES = '-||-'¶

The links a reconstruction finds (see reconstruct()), as KNet writes them: A --> B (A includes B), A <-- B (B includes A), A -|- B (A excludes B), and A -||- B (A coexcludes B).

snplugins.rnetReader.probes.reconstruct(found)¶
Parameters:

found (Probes)

Returns:

The links the probes say hold (see the module doc, and INCLUDES …): each node’s, to each node (in netNodes()’s order) – none to itself but an exclusion or coexclusion (an inconsistent node’s).
