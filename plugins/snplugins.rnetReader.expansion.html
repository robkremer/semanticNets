snplugins.rnetReader.expansion module¶

Editing a KNet net without changing what it says (Gaines, sections 2.4, 3.3 and 3.4): the nets each of these makes are equivalent to the one it’s done to, but for what the new nodes are.

  • expandProtoconnectives(): a node whose label groups others’ – a protoconjunction (“A ∧ B”, or “A & B”) or a protodisjunction (“A ∨ B”, or “A | B”) – is just notation: its links are those of its members (see EXPANDS), and it’s replaced by them;

  • addAnonymous(): single-node expansion – an anonymous node (an ideal element: no label) below a node, or above it, linked to it by one inclusion: ultra-conservative (it says nothing about the net);

  • factor(): factoring – where some nodes each have the same kind of link to each of some others, an anonymous node interpolated between them carries those links (eg: I and J each including A, B and C: I and J include it, and it includes A, B and C), in fewer links (Gaines’s figure 28: 12 become 10).

Each changes the model through a view’s context (as one command, undone in one go), if it’s given one.

snplugins.rnetReader.expansion.EXPANDS = {'coexcludes': ('conjunction', 'conjunction'), 'excludes': ('disjunction', 'disjunction'), 'includes': ('disjunction', 'conjunction')}¶

The kernel’s links a protoconnective at one of their ends is shorthand for – one link for each of its members – and which kind it must be at each end (tail, head). Extensionally (A includes B: A’s instances are B’s):

  • X includes A ∧ B: X includes A, and X includes B; and A ∨ B includes X: A includes X, and B does;

  • X excludes A ∨ B (either way round): it excludes A, and it excludes B (nothing’s in X and in A or B);

  • X coexcludes A ∧ B (either way round): it coexcludes A, and B (everything’s in X or in both A and B).

The others don’t come apart into links of their members (eg: X includes A ∨ B says less than either; X negates A ∧ B, or is equivalent to it, says more than links of its members can): a protoconnective with one of them isn’t expanded. Nor is a protoconjunction marked false, or a protodisjunction marked true; one marked true is a protoconjunction whose members are true, and one marked false a protodisjunction whose members are.

snplugins.rnetReader.expansion.addAnonymous(node, below=True, context=None)¶

Gaines’s single-node expansion (section 3.3): add an anonymous node – an ideal element, of node’s SN type, drawn without a label – linked to node by one inclusion (of the net’s: see linkType()). With at most one link, it’s an ultra-conservative merge: it says nothing new about the net, and taking it out again changes nothing.

Parameters:

  • below (bool) – Whether it’s below node (it includes node: something more specific), or above it (node includes it: something more general).

  • context (Any) – A view’s ModelContext, to do it as one command (undone in one go); or None, to add it to the model as it is.

  • node (Node)

Returns:

The node made, and its link.

Return type:

list[GraphObject]

snplugins.rnetReader.expansion.FACTORS = ('includes', 'excludes', 'coexcludes')¶

The kinds of link factor() factors: where each of some nodes (T) has one to each of some others (H), it interpolates an anonymous node α –

  • includes (T includes H): T include α, and α includes H;

  • excludes: T include α, and α excludes H;

  • coexcludes: α includes T, and α coexcludes H

– so each of T has the link to each of H still, through α (by the kernel’s patterns), and α could be any node between them: the import is ultra-conservative.

snplugins.rnetReader.expansion.planFactors(model)¶
Parameters:

model (Model)

Returns:

The factorings factor() does in model’s net, in turn: each the one (of each kind, in FACTORS’ order) that saves the most links – T and H at least two nodes each, and more links between them than there are nodes (the size of T times that of H is more than their sum) – among the net’s links not factored already. (Greedy: the fewest links in all may take others.)

Return type:

list[Factor]
