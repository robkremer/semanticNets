snplugins.rnetReader.forms module¶

A KNet net as a whole (Gaines, section 3: the dynamics of logical structures): its canonical forms, saturating it with probes, and what merging it with another net does.

  • minimalForm(): the net without its links that the rest imply (see redundantLinks()) – unique but for which links of a cycle stay;

  • maximalForm(): the net with every link the kernel’s patterns infer (see maximalLinks()), asserted;

  • saturate(): the net with its probes (see probes) added as nodes of PROBE, from outside: each includes the nodes true in it and excludes those false in it;

  • checkMerge(): whether merging another net into it (their nodes with the same label one) is consistent (no new inconsistent links), conservative (no new links in the other net) and ultra-conservative (none in either).

Each changes the model through a view’s context (as one command, undone in one go), if it’s given one.

Created on Nov 12, 2026

Code author: Rob Kremer <robkremer@me.com>

snplugins.rnetReader.forms.PROBE = 'probe'¶

The SN type (in the KNet rules model, an SN subtype of reader.KNODE that isn’t the net’s: see reader.KNET_NODE) of the probes saturate() adds.

snplugins.rnetReader.forms.SATURATION_LIMIT = 64¶

The most probes saturate() adds: each is a node in the view.

Returns:

The links of model’s net (see netLinks()) that the rest imply (see sn.model.reasoner.Reasoner.redundant()), in the net’s order: each, tried newest first, is redundant if its kernel types (see kernelOf()) still hold between its ends without it – and those found so stay out while the rest are tried. (Eg: KNet’s derived links, and A includes C beside A includes B and B includes C.) Newest first, so that what was added last goes first: eg, what maximalForm() asserted, and the net’s own links stay – the minimal form of its maximal form is the net’s.

snplugins.rnetReader.forms.saturate(model, kind='admissible', context=None, limit=64, engine=None)¶

Saturate model’s net (Gaines, section 3.6): add each of its probes (see probes.findProbes(): admissible ones, by default) as a node of PROBE, named “probe 1” and so on, that includes each node true in it and excludes each node false in it (both, for one both). They’re probes of the whole net: each is one of each part’s.

Parameters:

  • context (Any) – A view’s ModelContext, to do it as one command (undone in one go); or None, to add them to the model as it is.

  • limit (int) – The most probes to add.

  • model (Model)

  • kind (str)

  • engine (str | None)

Returns:

The nodes and relations added (the nodes first).

Return type:

list[GraphObject]

Raises:

  • TooManyProbes – If there are more than limit.

  • ValueError – If the model isn’t built on the KNet rules model (it has no PROBE).
