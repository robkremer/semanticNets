snplugins.rnetReader.hooks module¶

The hooks (see sn.hooks) that the KNet kernel model (knet.snm: see tools/makeKnetRules.py) names on knode, for Gaines’s truth marks – a node is true (T: what it stands for holds), false (F), both (Belnap’s “both”: inconsistent), or unmarked:

  • vis/sideBars (markBars()): a vertical bar beside a node that’s marked true, and a horizontal one over a node that’s marked false, as Gaines draws them, in the colour of how it got the mark (see MARK_COLORS);

  • .menu/Mark/True, .menu/Mark/False (markTrue(), markFalse()): assert a mark on the selected nodes, and .menu/Mark/Clear (clearMarks()): take back the marks asserted on them;

  • .menu/Probes... (showProbes()): show the probes of the node’s net (see probes);

  • .menu/Net/Minimal form, .menu/Net/Maximal form (minimalForm(), maximalForm()): put the node’s net in Gaines’s canonical forms (see forms): take out the links the rest imply, or assert those they do;

  • .menu/Net/Saturate (saturate()): add the net’s admissible probes, as nodes linked to it (see forms.saturate());

  • .menu/Net/Check merge with... (checkMerge()): what merging another net (a model, or a Rep Plus net file) into it would do (see forms.checkMerge()), in a window (see showMerge());

  • .menu/Mark/Abduce (abduce()): KNet’s abductive inference from the node: the marks that hold whatever explains it (see abduction);

  • .menu/Expand/Anonymous node below, .menu/Expand/Anonymous node above (addAnonymousBelow(), addAnonymousAbove()): Gaines’s single-node expansion (see expansion.addAnonymous());

  • .menu/Net/Expand protoconnectives (expandProtoconnectives()): its nodes whose labels group others’ replaced by them (see expansion.expandProtoconnectives());

  • .menu/Net/Factor (factor()): anonymous nodes interpolated to carry the links some nodes each have to each of some others (see expansion.factor());

  • .menu/Existence/Essentially top, .menu/Existence/Essentially bottom, .menu/Existence/Unspecified (essentiallyTop(), essentiallyBottom(), unspecified()): specify what the selected nodes essentially are, and .menu/Net/Existence... (showExistence()): the existential status of the net’s nodes, in a window (see existence).

A mark is two attributes, MARK_TRUE and MARK_FALSE, each saying how the node got it: “asserted” (by these menu items, or a net’s file), or by the kernel’s rules – “included” (it’s included by something true), “excluded” (it excludes something true), “coexcluded” (it coexcludes something false), or “irrelevant” (Rep Plus’s name: it includes something false). The reasoners conclude those (see knet.snm’s mark rules); “reason” shows them. Or “abduced”, by abduction (see abduce()): until the next “reason”.

snplugins.rnetReader.hooks.MARK_TRUE = 'markTrue'¶

The attributes that mark a node true or false: their values say how it got the mark (see the module doc).

snplugins.rnetReader.hooks.MARK_FALSE = 'markFalse'¶

The attributes that mark a node true or false: their values say how it got the mark (see the module doc).

snplugins.rnetReader.hooks.ASSERTED = 'asserted'¶

How a mark the user (or a net’s file) gives a node got there.

snplugins.rnetReader.hooks.MARK_COLORS = {'abduced': '#800080', 'asserted': '#693804', 'coexcluded': '#0000ff', 'default': '#800080', 'definition': '#ff0000', 'excluded': '#00a000', 'included': '#000000', 'irrelevant': '#a9a9a9', 'necessary': '#ff0000'}¶

Each way a node gets a mark -> its bar’s colour: Rep Plus’s mark kinds’ (Gaines’s paper’s: brown asserted, black and blue true, grey and green false; KNet draws what it abduces as defaults). Another (eg: a net’s own mark kind) is drawn black.

snplugins.rnetReader.hooks.SIDES = {'markFalse': 'top', 'markTrue': 'right'}¶

Where each mark’s bar goes (see sn.view.graphics.decorators.SideBars): true’s beside the node, false’s over it.
