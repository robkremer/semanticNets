snplugins.XMLreader.schema module¶

What an XML file’s tags and attributes are (see Schema), inferred from how they’re used throughout the file – not from their names, except as hints – so the reader (see reader.buildModel()) can make a model that matches what the file means:

  • Property tags: a tag with no subelements, that’s never repeated within any element it’s in (eg: <title> in a <book>), is a property of the element it’s in – an attribute of its individual, “property/<tag>” – not an individual of its own. Its value is its text; or, if it has none, its attribute, if it has just one (eg: <author name=”Hofstadter”/>).

  • Groups: likewise, a tag that’s never repeated within an element, has no text nor attributes of its own, and holds only properties and groups (eg: <States> in a <Device>), is part of the element it’s in: what it holds are properties of that element, “property/<group>/<tag>”.

  • Node tags: every other tag – one that has subelements, or is repeated in an element – is a type, and each of its elements an individual.

  • List holders: a node tag whose elements hold nothing but elements of one other node tag (eg: <DeviceList> holding <Device>s) isn’t made: the element it’s in has the elements it holds, by a relation named for it (has-DeviceList).

  • Annotations: an XML attribute that’s on several tags (with more than one element), and has the same value on all the elements of almost every one of them, from only a few values (eg: type=”integer”), says what the tag is, not what each element is: it’s noted on the type (or the property), not given to each element.

  • Fields: the rest of a node element’s XML attributes, and its property subelements, are its fields: “property/<name>” (a subelement’s wins: an attribute of the same name is “property/@<name>”). A property’s own attributes, besides its value, are “property/<tag>/<attribute>”.

  • Datatypes: a field whose values are all integers (or all numbers, or all true or false) is one: its values are stored as such.

  • Kinds: a node tag’s field whose name says it’s a kind (it has “type”, “kind”, “category” or “class” in it), whose values are names (not numbers) that recur, makes a subtype of the tag’s type for each value (eg: <book kind=”novel”>, or <Device><TypeName>Dimmer</TypeName>…).

  • Names: an element’s individual is named by its field called name, title, label, id, key or identifier (the first it has, ignoring case); or by its text, if that’s short; or by its tag and a number.

  • References: a field called id (or identifier, key, uuid, guid) is an identifier; a field whose name ends in id or ref (eg: DeviceID, ref), most of whose values are identifiers, refers to the elements they identify: its values become relations too, named for the field.

What an ontology made before says (see Hints) wins: eg: a tag that’s a type there stays a node tag, and one that’s a property of a type there stays a property.

snplugins.XMLreader.schema.PROPERTY = 'property/'¶

The prefix of the attributes made of fields (see the module doc).

snplugins.XMLreader.schema.NAMING = ('name', 'title', 'label', 'id', 'key', 'identifier')¶

The fields an element’s individual is named by (the first it has, ignoring case), in order.

snplugins.XMLreader.schema.IDENTIFIERS = ('id', 'identifier', 'key', 'uuid', 'guid')¶

The fields that identify an element, for references to it (ignoring case).

snplugins.XMLreader.schema.REFERENCE = re.compile('(id|ref|idref)$', re.IGNORECASE)¶

A field whose name matches this may refer to elements (see the module doc).

snplugins.XMLreader.schema.KIND = re.compile('type|kind|category|class', re.IGNORECASE)¶

A field whose name matches this may say what kind of thing an element is (see the module doc).

snplugins.XMLreader.schema.KIND_DIFFERENT = 5¶

A field whose values are all different, and there are more than this many, isn’t a kind (they’re names).

snplugins.XMLreader.schema.SHORT_TEXT = 40¶

An element’s text up to this long (and on one line) names its individual, if nothing else does.

snplugins.XMLreader.schema.ANNOTATION_TAGS = 3¶

An attribute on fewer tags than this (with more than one element) isn’t an annotation.

snplugins.XMLreader.schema.ANNOTATION_CONSTANT = 0.9¶

The share of an annotation’s tags whose elements all have the same value for it.
