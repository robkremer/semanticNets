snplugins.pythonParser.source module¶

Finding the source of a class, function or __main__ block – a chunk – again, in its file as it is now: the model keeps only where it was (its “line” and “end-line”) and what it looked like (its first line, and a hash of its text: see chunkAttrs()), not the code itself, so that small changes to the file don’t lose it.

locate() looks for it, in turn:

  1. by its name (eg: Class.method), in the file parsed afresh: found wherever it’s moved to in the file, whatever’s changed in it – unless it’s been renamed (or moved to another class);

  2. failing that (eg: the file doesn’t parse just now), by a def name / class name line, the nearest to where it was;

  3. failing that (eg: it’s been renamed), by the line most like its first line was, near where it was;

  4. failing that, where it was – marked as a guess.

and says whether it’s changed since the model was made (its hash).

locateNode() does it for a node of a model made by the parser: its file is its module’s (found through the defines relations up to it).

snplugins.pythonParser.source.MAIN = '__main__'¶

The name of a module’s if __name__ == "__main__": part (a code node’s).

snplugins.pythonParser.source.HASH_LENGTH = 12¶

How many hex digits of a chunk’s hash are kept (see sourceHash()).

snplugins.pythonParser.source.FUZZY_CUTOFF = 0.6¶

How alike (0..1) a line must be to a chunk’s first line to be taken for it (see locate(), step 3).

snplugins.pythonParser.source.NAME = 'name'¶

How a chunk was found (see Location.how).

snplugins.pythonParser.source.GREP = 'grep'¶

How a chunk was found (see Location.how).

snplugins.pythonParser.source.FUZZY = 'fuzzy'¶

How a chunk was found (see Location.how).

How a chunk was found (see Location.how).
