snplugins.XMLreader package¶

XMLreader: a plugin (see sn.plugins) that makes a model of an XML file – a type for each tag that’s a thing, and an individual for each of its elements, with properties for the tags that are values, and relations for their nesting (each a kind of xml-has-part) and references, inferred from how they’re used (see schema) – on an ontology of its own (the types, and the definition of xml-part-of), and a view of it, arranged, from the Tools menu’s “XML Reader…”.

  • reader: reads the XML file, and makes the model;

  • schema: what the file’s tags and attributes are, from how they’re used;

  • view: the front end, and the view;

  • examples: some XML files to try.

Created on Oct 3, 2026 (a plugin since Oct 17)

Code author: Rob Kremer <robkremer@me.com>

snplugins.XMLreader._dialog: Any = None¶

The dialog, while it’s open: the menu item brings it to the front rather than opening another.

snplugins.XMLreader.register(ctx)¶

Add “XML Reader…” to the Tools menu (see sn.plugins.PluginContext): its dialog (see view.ReaderDialog) asks for the file – in the folder last read from, or at first the plugin’s examples – and the files to make of it, and makes them (see view.convert()). An ontology given by hand (eg: one shared by XML files of the same kind) is offered again next time, in place of the one beside the model – if it’s still there – until one’s made beside the model again. Those of the plugin’s own examples are made in the example models’ folder (see Application.EXAMPLES_FOLDER) by default, not in the plugin’s folder, which is replaced when a newer version’s installed.

Parameters:

ctx (sn.plugins.PluginContext) – The plugin’s context.

Return type:

None
