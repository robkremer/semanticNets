The Semantic Nets package is a tool for …

sn.VERSION = '1.0.1'¶

The program’s version: written in the files it saves (see SerializationStrategy.appVersion).

sn.SCHEMA_VERSION = '1'¶

The version of the structures of models and views, as they’re saved: written in their files’ heads (“schema”, “schemaVersion”: see Model.serializationHeader()), so that a file saved with older ones can be recognised and brought up to date when it’s read. Change it whenever they change (eg: a property’s renamed, or its meaning changes).

sn.copyExamples(target, names=None)¶

Copy the example models that come with the program (see exampleNames()) into the folder target (made if need be), and make each copy refer to where it now is – they’re stored as being in EXAMPLES_PLACEHOLDER – so that it isn’t taken to have been moved when it’s opened.

Parameters:

  • names (list[str] | None) – The files to copy (eg: [“family.snm”, “family.snv”]); by default, all of them.

Returns:

The preferences: key -> (type, default, note). Each is in the preferences (snPrefs) from the start, with its default if the file doesn’t have it – so a missing preferences file (the first run, or deleted to start afresh) is made from these – and with its note (unless the user has written their own: see Attribute.userNote). A preference can still be made on the fly (by snPrefs.get(key, storeDefault=…)), but it should be added here, so it has a note. Keys starting with “.” – kept by the program for itself – aren’t here: the settings editor doesn’t show them.

sn.checkSaveModified(obj, url, kind)¶

Check whether obj has unsaved changes and, if so, ask the user whether to save it before it’s discarded – either because its window is being closed (see sn.view.graphics.guiApp.Application._closeWindow()) or because the whole app is exiting (see saveAtExit() below).

Pulled out of saveAtExit() as a shared helper so both call sites – the whole-app-exit path and the individual-window-close path – prompt with exactly the same writeLocked()/isDirty()/save() logic instead of drifting apart.

Parameters:

  • obj (util.persistence.pRef.PRDb) – The database-backed object to check – a Model or SNGView (anything exposing writeLocked(), isDirty() and save()).

  • url (str) – obj’s URL, used only in the confirmation dialog’s message.

  • kind (str) – A lowercase human-readable noun for the confirmation dialog, e.g. “model” or “view”.

Return type:

None

If the environment variable SN_NO_SAVE_PROMPT is set (to anything), nothing is asked and nothing is saved – for automated runs, such as tests, which would otherwise put a dialog on the screen for every modified model.

sn._savedAtExit = False¶

Set once saveAtExit() has run, so the atexit call after an explicit one doesn’t ask again.

sn.saveAtExit()¶

Offer to save every modified model and any still-open view. Runs at most once per process: eg: the Quit handler calls it explicitly and then exits, which would otherwise run it again (via atexit) and repeat every question the user already answered “no” to.
