sn.view.graphics.viewVisibility module¶

What a graphical view hides or erases (VisibilityMixin): one of the parts of sn.view.graphics.sngView.SNGView (see viewBase).

Created on Oct 18, 2026 (from sngView.py)

Code author: Rob Kremer <robkremer@me.com>

sn.view.graphics.viewVisibility.RELATION_CATEGORY = 'relations: '¶

How a relation type’s category (for hiding or erasing its relations) is named: see SNGView.relationCategory().

sn.view.graphics.viewVisibility.NODE_CATEGORY = 'nodes: '¶

How a node type’s category (for hiding or erasing its individuals) is named: see SNGView.nodeCategory().

class sn.view.graphics.viewVisibility.VisibilityMixin¶

Bases: ViewBase

What a view (sn.view.graphics.sngView.SNGView) shows: the categories of model objects (eg: types, rules, a relation type’s relations) it hides or erases (saved with the view), what’s exempt for now, what’s hidden in a collapsed window, and doing it all in one pass over the canvas.

isFiltered(mo, modes=('hide', 'erase'))¶

True iff mo is in a category currently in one of modes (see hides).

Parameters:

  • mo (GraphObject)

  • modes (Iterable[str])

Return type:

bool

_erasedRelation(rel)¶

Whether a new relation shouldn’t be shown: it would bring an end in an erased category back into the view. (A relation that’s in an erased category itself is shown, as anything made is: see _exemptIfFiltered().)

Parameters:

rel (Relation)

Return type:

bool

_exemptIfFiltered(vo)¶

vo was just made (or shown explicitly): if it’s in a hidden or erased category, show it anyway – hiding is “soft”: it applies to what was there when the category was hidden, and hiding the category again hides this too – and say so (one message for everything made at once).

Parameters:

vo (VObject)

Return type:

None

_reportExempt()¶
Return type:

None

shouldHide(vo)¶

Whether vo shouldn’t be drawn just now: it’s in a hidden category; or it’s a relation to or from something hidden (it would lead nowhere), or a containment drawn as being inside its window (see VRelation.inWindow()); or it’s inside a hidden context’s window.

Parameters:

vo (VObject)

Return type:

bool

_inCollapsedWindow(vo)¶

Whether vo is drawn inside a collapsed context window (see VObject.setCollapsed()), and so not shown.

Parameters:

vo (VObject)

Return type:

bool

_inShownContext(vo)¶

Whether vo is part of a shown context window’s content (eg: an isa link in a rule’s consequent): it’s then shown whatever its category – it’s what the rule says, not clutter.

Parameters:

vo (VObject)

Return type:

bool

applyVisibility()¶

Bring every object into line with the current hides (see VObject._applyHidden()).

Return type:

None

_visibilityMenu(mode)¶

A checkbox per category for mode (“hide” or “erase”): checking it sets that category to mode (so unchecks it in the other menu); unchecking it shows the category again. The relation and node types’ categories (see relationCategory(), nodeCategory()) are listed only while they’re hidden or erased; “relation types…” and “node types…” choose them (see chooseRelationCategories(), chooseNodeCategories()).

Parameters:

mode (str)

Return type:

Menu

relationCategory(typ)¶

The category of the relations of a relation type, and of its subtypes (not the type itself, nor isa links: see the “isa individuals” category), for hiding or erasing (see visibility()): made the first time it’s asked for.

Parameters:

typ (Relation | str) – The relation type, or its name.

Returns:

The category’s name: RELATION_CATEGORY and the type’s: eg: “relations: imports”.

Return type:

str

nodeCategory(typ)¶

The category of the individuals of a node type, and of its subtypes (not the types themselves: see the “types” category; nor relations), for hiding or erasing (see visibility()): made the first time it’s asked for.

Parameters:

typ (Node | str) – The node type, or its name.

Returns:

The category’s name: NODE_CATEGORY and the type’s: eg: “nodes: person”.

Return type:

str

_setHides(text)¶

Put back the hidden and erased categories saved with the view (see hides), making those of relation and node types (see relationCategory(), nodeCategory()).

Parameters:

text (str) – What was saved: eg: “types=hide,relations: imports=erase”.

Return type:

None

_shownModelObjects()¶
Returns:

The ids of the model objects shown in the view (not erased: hidden ones too).

Return type:

set[int]

showRelationsOfTypes()¶

“show” > “relations…”: choose relation types in a dialog, and show their relations (and their subtypes’) between the nodes in the view – and, if asked, with the nodes at their other ends too. Shown even if they’re in a hidden or erased category (they were asked for by type: see _exemptIfFiltered()). One undoable command (see represent()).

Return type:

None

showNodesOfTypes()¶

“show” > “nodes…”: choose node types in a dialog, and show their individuals (and their subtypes’) – and, if asked (the default), their relations to what’s shown, and to each other (not those in a hidden or erased category). The nodes are shown even if they’re in a hidden or erased category (they were asked for by type: see _exemptIfFiltered()). One undoable command (see represent()).

Return type:

None

_showObjects(objects, what)¶

Show objects in the view, as one undoable command (see represent()) – or, if there are none, say so.

Parameters:

  • objects (list[GraphObject]) – Model objects: nodes before relations.

  • what (str) – What they are, for the message if there are none: eg: “relations of those types”.

Return type:

None

chooseRelationCategories(mode)¶

“relation types…”: choose, in a dialog, the relation types whose relations (and their subtypes’) to hide or erase (mode); those unchecked that were are shown again. Done as one undoable command.

Parameters:

mode (str) – “hide” or “erase”.

Return type:

None

chooseNodeCategories(mode)¶

“node types…”: choose, in a dialog, the node types whose individuals (and their subtypes’) to hide or erase (mode) – and with them, their relations; those unchecked that were are shown again. Done as one undoable command.

Parameters:

mode (str) – “hide” or “erase”.

Return type:

None

_applyWhere(mo)¶

A new object’s name was typed with constraints, eg: “?p :where: alive”: make them its “constraints” attribute. Only variables have constraints; for anything else, or constraints that can’t be read, the name stays as typed (and a message says why).

Parameters:

mo (GraphObject)

Return type:

None

batchedItemStates()¶

Within it, objects’ hiding and showing their canvas items (see VObject._hideItems(), VObject._showItems()) is put off, and done at the end in one pass over the canvas – instead of a search of the whole canvas for each object’s items, which is slow for many objects in a big view (eg: doEraseOthers(), or a model’s notification that takes many out, or puts them back: see SNGView.update()). Nested, only the outermost does it.

Return type:

Iterator[None]
