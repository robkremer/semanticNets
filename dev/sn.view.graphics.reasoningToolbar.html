sn.view.graphics.reasoningToolbar module¶

The reasoning toolbar: a strip across the bottom of a view’s window with small icon buttons (each with a tooltip) to Reason (run the reasoner over the view’s model: see sn.model.reasoner.reason()), Reason silently (the same, without adding what it infers to the views: see SNGView.reasonSilently()) and Retract (take what it inferred back out: see sn.model.reasoner.clearReasoning()), and a line saying what the last “reason” found. Reasoning isn’t redone as the model is edited, so it’s a click away. At its right, a pencil says whether the view’s model can be edited – crossed out if it can’t: the view’s locked, or the model’s write-locked (eg: the system model, or the base rules). Clicking it locks or unlocks the view (see SNGView.setEditLocked()), except a write-locked model’s, as “Edit | Lock view” does. Next to it is the view’s zoom (see SNGView.zoom()). Shown and hidden with “View | Reasoning toolbar” (see SNGView.showReasoningToolbar()).

class sn.view.graphics.reasoningToolbar.ReasoningToolbar(master, view)¶

Bases: Frame

The reasoning toolbar for a view: see the module doc.

Parameters:

  • master (tk.Misc)

  • view (SNGView)

PADDING = 4¶

The toolbar’s padding (pixels) at its left and right.

ICON_WIDTH = 2¶

The width (characters) of the toolbar’s icon buttons.

LOCK_SIZE = 18¶

The width and height (pixels) of the pencil that says whether the model can be changed in the view.

__init__(master, view)¶
Parameters:

  • master (tk.Misc) – The widget it’s in: the view’s window.

  • view (SNGView) – The view whose model it reasons over.

refresh()¶

Show what the view’s model’s last “reason” found (see SNGView.reasoningSummary()), and enable Retract only if there’s something to retract.

Return type:

None

refreshLock()¶

Show whether the model can be changed in the view (see SNGView.isModelEditor()): the pencil, or the pencil crossed out. It’s a button unless the model’s write-locked.

Return type:

None

toggleLock()¶

The pencil’s clicked: lock the view so it can’t change the model, or unlock it (see SNGView.setEditLocked()) – not a write-locked model’s.

Return type:

None

refreshZoom()¶

Show the view’s zoom, as a percentage (eg: “150%”).

Return type:

None
