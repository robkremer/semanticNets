sn.model.nemoReasoner module¶

A Reasoner engine built on Nemo (Datalog with stratified negation and aggregates, from TU Dresden), through its Python bindings (pip install nemo-python, imported as nmo_python).

The engine-neutral facts from Reasoner.facts() are rendered as Nemo facts, the rule base in nemoReasoner.rls (a port of clingoReasoner.lp) is applied, and the results are mapped back onto the model’s GraphObjects. Every GraphObject is a constant <#N>.

Unlike clingo, Nemo can say how it reached a conclusion: see NemoReasoner.explain().

Where the two differ (see nemoReasoner.rls): a rule’s negated attribute test (“not gender: female”) is about the attributes the model gives, not those other rules conclude – Nemo needs the program stratified as a whole before it runs.

class sn.model.nemoReasoner.NemoReasoner(model, rules=PosixPath('/Users/kremer/git/semanticNets/src/sn/model/nemoReasoner.rls'), showSysRules=None)¶
