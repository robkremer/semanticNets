sn.model.clipsReasoner module¶

A Reasoner engine built on CLIPS (a forward-chaining production system), through its Python bindings, clipspy (pip install clipspy, imported as clips).

The engine-neutral facts from Reasoner.facts() are rendered as CLIPS ordered facts, the rule base in clipsReasoner.clp (a port of clingoReasoner.lp) is applied, and the results are mapped back onto the model’s GraphObjects. Every GraphObject is a symbol #N.

CLIPS fires a rule as soon as its conditions match, so a rule that tests that something isn’t so – a (not ...) – must wait until what it tests is complete. The engine sees to that: it sorts the rules (the rule base’s, the model’s and a query’s) into strata, and gives each rule a salience by its stratum (see _stratify()); a program that can’t be sorted so (it isn’t stratified) is refused.

Where the engine differs from clingo (see clipsReasoner.clp): a rule’s negated attribute test (“not gender: female”) is about the attributes the model gives, not those other rules conclude – as for Nemo.

sn.model.clipsReasoner._stratify(rules)¶

Sort rules into strata (each rule’s stratum), so that a rule that tests with (not …) fires only once every rule that could conclude what it tests has: the predicates fall into groups that conclude each other (CLIPS runs each group to its end), and a group that another tests with (not …) runs first. Within a group no rule may test another’s conclusions with (not …): that isn’t stratified (and isn’t a question of when it runs).

Parameters:

rules (list[_Rule])

Return type:

None

Raises:

sn.model.clipsReasoner._ordered(conditions)¶

conditions (a rule’s), in the order CLIPS should match them. CLIPS matches a rule’s conditions in order, keeping every partial match: a pattern that shares no variable with those before it multiplies them (eg: (data ?x) (data ?y) (data ?z) before the relations between them). So: first a pattern with a constant, then each pattern that shares the most with those already matched – and each test, and each (not …), as soon as the variables it tests are bound (a variable that’s only in a (not …) is its own).

Parameters:

conditions (list[str])

Return type:

list[str]
