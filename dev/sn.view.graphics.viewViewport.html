sn.view.graphics.viewViewport module¶

A graphical view’s zooming, scrolling and painting (ViewportMixin): one of the parts of sn.view.graphics.sngView.SNGView (see viewBase).

Created on Oct 18, 2026 (from sngView.py)

Code author: Rob Kremer <robkremer@me.com>

class sn.view.graphics.viewViewport.ViewportMixin¶

Bases: ViewBase

How a view (sn.view.graphics.sngView.SNGView) is seen: zooming (and the font size that goes with it), scrolling, converting between window and view coordinates, and painting – now, or soon, and once everything’s been read.

_fontFace: str¶
_fontSize: float¶
_drawVersion: int¶
ZOOM_STEP = 1.25¶

How much “Zoom In” zooms in (and “Zoom Out”, out).

MIN_ZOOM = 0.05¶

The least and most the view zooms to.

MAX_ZOOM = 8.0¶

The least and most the view zooms to.

ZOOM_FIT_MARGIN = 20¶

Screen pixels left around everything by “Zoom to Fit”.

fontSize()¶
Returns:

The size of the view’s text at its zoom: at least 1 (a size of 0 is Tk’s default size: big, at a small zoom).

Return type:

int

zoomIn()¶

Zoom in a step (ZOOM_STEP), about the middle of the window.

Return type:

None

zoomOut()¶

Zoom out a step (ZOOM_STEP), about the middle of the window.

Return type:

None

_windowCentre()¶
Returns:

The point (view units) at the middle of the window.

Return type:

tuple[float, float]

_centreOn(x, y)¶

Scroll so the point (x, y) (view units) is at the middle of the window (as near as the scroll region allows).

Parameters:

  • x (float)

  • y (float)

Return type:

None

_scrollToPut(at, wx, wy)¶

Scroll so the point at (view units) is at (wx, wy) in the window (as near as the scroll region allows).

Parameters:

  • at (list[float])

  • wx (float)

  • wy (float)

Return type:

None

zoomAbout(scale, centre=None)¶

Zoom to scale (kept between MIN_ZOOM and MAX_ZOOM) with the same point at the middle of the window (not the view’s top left, as zoom() alone does: so things don’t jump away).

Parameters:

  • scale (float) – The zoom: 1 is normal size.

  • centre (tuple[float, float] | None) – The point (view units) to have at the middle of the window, if not the one there now.

Return type:

None

zoomToFit()¶

“Zoom to Fit”: zoom so everything shown fits in the window (with ZOOM_FIT_MARGIN around it), in the middle of it.

Return type:

None

zoom(scale=1.0, delta=False)¶
Parameters:

  • scale (float) – the absolute scale, where 1.0 is “no scaling”, unless delta is true, in which case, multiplier for the current scale (so numbers like 0.9 and 1.1 make sense).

  • delta – True to do relative scaling, False to do absolute scaling.

_viewportState()¶
Returns:

What’s saved with the view about what’s shown in its window (see _restoreViewport()): its zoom, and the point at its top left, in view units (as the view’s objects are placed): eg: “zoom=0.8;x=120.0;y=-40.0”.

Return type:

str

_restoreViewport()¶

Once a read view is built: zoom it as it was saved, and scroll it so the same point is at its top left (see _viewportState()).

Return type:

None

viewToWindow(*args)¶
Parameters:

args – Either a single list argument or multiple float parameters. In either case there must be an even number of items, taken as x,y pairs. Since scaling is x:y equal, this “even” limitation is relaxed here.

Returns:

A list converted coordinates where the evens are x coordinates and the odds are y coordinates converted from view to window coordinates.

Return type:

list[float]

windowToView(*args)¶
Parameters:

args – Either a single list argument or multiple float parameters. In either case there must be an even number of items, taken as x,y pairs. Since scaling is x:y equal, this “even” limitation is relaxed here.

Returns:

A list converted coordinates where the evens are x coordinates and the odds are y coordinates converted from window to view coordinates.

Return type:

list[float]

freshPaint()¶

Increments self._drawVersion so that graphic options can know whether to update of not.

repaintSoon()¶

Repaint the whole view (see repaint()) once things are idle – once, however many times this is called before then: eg: the moves of a whole run of the animation layout, recorded (or undone) as one command, each of which would otherwise repaint everything.

Return type:

None

_drawAllAfterRead()¶

Once a read view is built: draw everything – nodes first, then relations, so each relation is drawn once its ends are where (and the size) they’ll be. The objects’ own first drawings, queued as they were made, were put off till now (see VObject._firstDraw()): each was a redrawing of all of a node’s relations as it was fitted to its text, and then this drew them all again.

Return type:

None

refreshAllCaches()¶

Refresh every object’s cache of its model object’s visual attributes (see vobjects.Cache.refresh()), and repaint the view, so it shows them.

Return type:

None

repaint(event=None)¶
Parameters:

event – The Tk event.

resetScrollRegion(shrink=False)¶

Recompute the canvas’s scroll region from the current extent of everything actually drawn on it, and apply it – to self.scrollRegion itself (what VObject.moveTo()/boundingBox() clamp positions against – see their docstrings) as well as to the canvas widget’s own scrollregion configuration option.

Parameters:

shrink (bool) – [default=False] Normally the region only grows (see below); True fits it to the drawing even if that makes it smaller – for an explicit user request, when the view jumping to fit is expected.

Return type:

None

Called by VObject.draw() whenever a VObject’s bounding box no longer fits inside the existing region – e.g. after it’s been dragged past the SE edge – so the canvas grows to keep the object reachable/visible.

Parameters:

shrink (bool)

Return type:

None

Note:

Nothing’s caught here: self.canvas.bbox(“all”) is None while nothing’s drawn, which is checked for (expandRect(None, 100) would raise TypeError); anything else is a real fault, and masking it would leave the region silently not grown (eg: when dragging past the edge). self.scrollRegion is kept in step with the canvas’s, as moveTo()’s clamp compares against it.
