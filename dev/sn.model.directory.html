sn.model.directory module¶

The model/view directory: the models (.snm) and views (.snv) in a list of folders – the search path, like the shell’s PATH – found without reading them: only each file’s header and the first few properties of the object in it (its type, URL, and – for a view – its model) are read (see peekFile()).

The search path is a string of folders separated by “;”, by new lines, or (but for Windows, where it’s in “C:...”) by “:”, as in the shell’s PATH (see os.pathsep). A folder ending in /** includes all the folders below it, too (see parsePath()). The window showing the directory is sn.view.graphics.directoryWindow.DirectoryWindow.

Created on Oct 12, 2026

Code author: Rob Kremer <robkremer@me.com>
