_QUERY_SPECIAL_SYMBOLS = ['?', '*']¶
query(objects, /, model=None, astree=False, keepdups=False)¶

Query a model in one of <fetch>, <type>, or <relation> expression forms.

  • <obj> # “echos” the referenced object (str->GraphObject)

  • <type> <obj> # <obj> isa <type>

  • <obj1> <relation> <obj2> # <obj1> is related to <obj2> by <relation>

where any of the of the tokens may be an reference to an object or one of the query tokens “?” or “*”. If a query token does not appear in the expression, it will return a boolean answer. If one query token appears in the expression, the answer will be a list of objects that satisfy the expression. If two query tokens appear in the expression, the answer will be a list of pairs (tuples) that satisfy the expression.

The difference between “?” and “*” only applies to <type> queries: “?” returns results only one level deep (eg: direct parents), while “*” returns transitive and reflexive results (eg: self and all ancestors).

Examples:

  • query person -> Node(“person”, #19, <type>)

  • query person ? -> Node(“Fred”, #21, <individual>), Node(“Jane”, #23, <individual>)

  • query ? Jane -> Node(“person”, #19, <type>)

  • query * Jane -> Node(“Jane”, #23, <individual>), Node(“person”, #19, <type>),

    Node(“node”, #6, <type>), GraphObject(“top”, #1, <type>)

  • query Jane isa person -> True

  • query ? isa person -> Node(“Fred”, #21, <individual>), Node(“Jane”, #23, <individual>)

Parameters:

  • objects (list[str | GraphObject]) – The objects in the expression (up to 3)

  • astree (bool) – If True return a list result of <type> expression as a “tree list”.

  • keepdups (bool) – If True do not remove duplicates from a list result of <type> expression.

  • model (Model | None) – The model to look in. Defaults to the default model.

assert_(objects, /, type=False, model=None)¶

Assert a predicate in the model; ie: create an object of some type, add a parent type to an object, or create a new relation between objects.

Examples:

  • assert node person –type -> Node(“person”, #19, <type>)

    {and IsaInstance(“isa”, #20, <individual>, #19 -> #?)} Create a type “person”

  • assert person fred -> Node(“fred”, #21, <individual>)

    {and IsaInstance(“isa”, #20, <individual>, #21 -> #19)} Create an instance of person, “fred”, assuming object “fred does not already exist. If “fred” doesn exist, then only the IsaInstance is created.

  • assert relation sibling –type -> Relation(“sibling”, #23, <type>, #1 -> #1)

    {and IsaInstance(“isa”, #24, <individual>, #23 -> #2)} Create a relation type “sibling”. (To make it symmetric, “set attribute sibling symmetric yes”.)

  • assert person sibling person -> Relation(“sibling”, #23, <type>, #19 -> #?19) (same one)

    Since “sibling” exists and person is a type, modify the src and dst both to be “person”.

  • assert person gorge -> Node(“gorge”, #26, <individual)

    {and IsaInstance(“isa”, #27, <individual>, #26 -> #19)}

  • assert fred sibling gorge -> Relation(“sibling”, #28, <individual>, #21 -> #26)

    {and IsaInstance(“isa”, #28, <individual>, #28 -> #23)} Create a new relation instance “sibling” between “fred” and “gorge”.
