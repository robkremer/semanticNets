__init__(owner, priority=0)¶
Parameters:

  • owner – The VObject this decorator is attached to.

  • priority (int) –

    [int, default=0] Where this decorator draws relative to the owner’s other decorators, lowest first – see VObject.draw(), which draws self.decorators.values() sorted by this. Ties keep insertion order (Python’s sort is stable), so existing decorators are unaffected by just leaving this at its default.

    This only orders decorators within one VObject’s own draw() call – it can’t reach across to order against a different VObject’s items, since canvas stacking is one global list, not per-object (see ShadowDecorator, which needs exactly that and uses canvas.tag_lower() instead).

preferredLayout(text)¶
Parameters:

text (str)

Returns:

(box width, box height, text wrap width), in view units, for text when the box is sized automatically:

  1. The text is broken into lines (see layoutText()) so that the text block’s own shape is as close as possible to “vis/aspectRatio” (height/width) – ties going to the smaller block.

  2. The box is sized to that block, but its width is kept within “vis/minSize”..”vis/maxSize”, and its height is width * “vis/aspectRatio”. Text too big for a “vis/maxSize” box overflows the shape, evenly on all sides.

  3. If “vis/aspectRatio” is 0 (free), the block is shaped to NOMINAL_ASPECT, and the box height is whatever the text needs (at least width * NOMINAL_ASPECT), capped at “vis/maxSize”.

  4. If “vis/minSize” == “vis/maxSize” the box is a fixed size.

Return type:

class sn.view.graphics.decorators.ContextFrame(owner)¶

Bases: Decorator

Draws a context (a rule, query, …) as a window: a title banner with its name and, for a rule, a divider between its antecedent (left) and consequent (right) panes, each labelled. The owner’s shape is the window body. The window is kept beneath everything else (but above any window it’s on: see SNGView.restackWindows()), so what it contains sits on top of it, and its body is left out of overlap avoidance (it’s retagged from “vis/shape” to “context-frame”), so objects can be placed inside it. See VObject.isContextWindow().

class sn.view.graphics.decorators.ShadowDecorator(owner, offset=(4, 4), **kwargs)¶

Bases: Decorator

Draws a plain “duplicate shape, grey, one z-order lower” drop shadow behind the owner’s own shape – the standard tk drop-shadow technique, rather than anything Pillow/raster-based (too costly to redraw/rescale for this).

Only drawn while snPrefs[“gui/shadowTypes”] is True (checked at each draw, so turning it off takes effect at once).

Does NOT yet support “vis/shadowColor” or any other attribute-driven customization – the constructor kwargs are the only knob for now. See Shape.shapeOptionsMap / Shape.updateKwargs() for the pattern to follow if/when that’s added later.

Parameters:

offset (tuple[int, int])
