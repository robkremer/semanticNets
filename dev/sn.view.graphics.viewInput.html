A graphical view’s mouse, keys and menus (InputMixin): one of the parts of sn.view.graphics.sngView.SNGView (see viewBase).

class sn.view.graphics.viewInput.InputMixin¶

Bases: ViewBase

What a view (sn.view.graphics.sngView.SNGView) does with the mouse and keys: its bindings; pressing, dragging and releasing (selecting, the drag-select box, panning, Option-drag zooming, grabbing a relation’s terminal); the elastic line that picks something for a command; the mouse wheel; and the view’s pop-up menus.

onEnter(_event)¶

Give this Canvas Tk keyboard focus whenever the mouse enters it.

All of this class’s key bindings (KEY_UNDO, KEY_REDO, KEY_REPAINT, …) are bound directly on self.canvas – like any Tk widget-level binding, those only fire while the canvas itself holds keyboard focus, and nothing else in this window (e.g. clicking into the canvas, as opposed to some other widget such as the terminal) ever calls focus_set() on it. Without this, the canvas can easily end up never holding focus at all, so a key like Cmd-Z is delivered nowhere and its binding never fires, even though the binding itself is set up correctly. This mirrors the equivalent binding in the older, now-superseded sn.view.graphics. view.SNView (see its own onEnter()), which was dropped somewhere along the way when this class superseded it.

Parameters:

_event (Event) – The Tk <Enter> event (unused).

None

onButton_1(event)¶
Parameters:

event – event.x and event.y contain the x,y coordinate of the click.

Returns:

None

If the SHIFT or COMMAND key is pressed: start a drag-scroll (panning the view – with COMMAND, over objects too: they leave the press to the canvas, see VObject.onButton_1()). If the OPTION key is: start a drag-zoom (over objects too), up to zoom in, down to zoom out, about where it was pressed (see ZOOM_DRAG). Otherwise, unselect everything and prepare for a possible selection box animation (if we get a move event).

Called on the <Button-1> event (when the mouse button 1 is pressed).

  • If self._makeRelationFrom is not None, return.

  • Check if the event has been handled by a contained widget. If it has been, call self.removeEventHandled() and return.

  • If the shift or command key is pressed start a scroll action and return.

  • If the option key is pressed start a zoom action and return (an Option-click on an object that doesn’t drag selects it and its relations instead: see VObject.selectWithRelations()).

  • Otherwise unselect everything and start a selection box action by setting up self._selectionBoxInfo.

onB1_Motion(event)¶
Parameters:

event – event.x and event.y contain the x,y coordinate of the click.

Returns:

None

If we are either drag-scrolling or drag-drawing a multi-selection box, continue the action.

Called on the <B1-Motion> event (when the mouse moves with button1 pressed).

  • Check if the event has been handled by a contained widget. If it has been, call self.removeEventHandled() and return.

  • If self._scrolling is not None, call self.scan_dragto().

  • If self._selectionBoxInfo is not None, redraw the elastic selection box, using self._selectionBoxInfo[3] to note that the selection box is active.

elasticLineChoice(originNode, callback, filter=<function InputMixin.<lambda>>, arrowHeads=2, color='cyan', onEmpty=None)¶

Animate an elastic line from the originNode to the cursor to select an object for which filter returns True, then call callback with the originNode and the selected object.

Parameters:

  • originNode (VObject) – The object to root the elastic line one (and used as the first parameter to callback.

  • callback (Callable[[VObject, VObject], Any]) – The method to call after a selected selection.

  • filter (Callable[[VObject], bool]) – Objects are only selected if filter(<obj>) returns True. [Optional, default=always True]

  • arrowHeads (int) – 0=no arrowheads, 1=arrowhead at the origin, 2=arrowhead at the cursor, 3=arrowhead at both ends. For anything larger, just he lowest 2 bits will be used. [Optional, default=2]

  • onEmpty (Callable[[VObject], Any] | None) – If given, called with originNode when the line is dropped on empty space (no object at all under the cursor); otherwise that abandons the choice, as Escape always does (see cancelElasticLine()).

  • color (str)

onB1_ButtonRelease(event)¶
Parameters:

event (Event) – event.x and event.y contain the x,y coordinate of the click.

Returns:

None

Return type:

None

Depending on the context, finish creating a Relation or create a selection set from the selection box that just finished.

  • Check if the event has been handled by a contained widget. If it has been, call self.removeEventHandled() and return.

  • Set self._scrolling to None.

  • If self._makingRelaionFrom is not None:

    • Create a link according to the data in the makeRelationData structure and the event’s x,y coordinates

    • set self._elasticLineChoiceData to None.

  • If self._selectionBoxInfo is not None: This means we have finished drawing a selection box, so

    • deselect everything,

    • select everthing in the selection box, and

    • set self._selectionBoxInfo to None.

isEventHandled(event)¶
Parameters:

event (Event) – The event to test.

Returns:

True iff event is the same physical event most recently passed to addEventHandled() (and not yet cleared by removeEventHandled()).

Return type:

bool

A canvas item’s tag_bind callback and this canvas widget’s own bind callback are dispatched independently by Tk, even for the exact same physical click – returning "break" from the item’s callback only suppresses other item bindings, not this canvas’s own separate widget-level binding for the same event. This flag is how a contained VObject/item-level handler tells this canvas’s own generic handler (e.g. onRightMouse()) “I already dealt with this one, skip your default behaviour.”

addEventHandled(event)¶

Mark event as handled by a contained VObject/item-level callback, so this canvas’s own separately-dispatched widget-level binding for the same event can detect that (via isEventHandled()) and skip its generic handling.

Parameters:

Return type:

None
