sn.plugins module¶

Plugins: programs the editor loads at start-up, that add to it – menu items for now (see PluginContext); panels, view menus and text commands later. (Eg: pythonParser and XMLreader, which come with it.)

A plugin is a folder in PLUGINS_FOLDER (~/.sn/plugins/): a Python package whose __init__.py defines register(ctx), and a plugin.toml describing it (see Manifest):

name = "My plugin"
version = "1.0"
description = "What it does."
sn-version = "1.0"     # the oldest sn it works with
exclude = ["examples/*.snm"]   # files in it not to install (see installBundled())

It’s imported as snplugins.<folder> (a package whose path is the plugins folder: see namespace()), so that its hooks (see sn.hooks) have the same references wherever it’s installed – eg: snplugins.myPlugin.hooks:show – and, once it’s loaded, they’re trusted: it was installed by the user.

The plugins that come with the program (bundledFolder(): the project’s plugins/; a packaged app’s bundled copy) are copied into the plugins folder (see installBundled()) when they aren’t there, are older, or have changed since they were installed (eg: edited in the project) – copied, not loaded where they are, so that what’s in them (eg: an ontology models are built on) stays at the same place when the app is moved or updated.

A plugin that can’t be read, imported or registered is logged, and left out: it doesn’t stop the program, or the other plugins. The “plugins/disabled” preference lists those not to load.

sn.plugins.installBundled(source=None, target=None)¶

Copy the plugins that come with the program into the plugins folder: those that aren’t there, are older there (by their version), or have changed since they were copied there (the same version, but not the same files: eg: edited in the project, between releases – see STAMP) – replacing them – but for the files they say not to (see Manifest.exclude), and making their models and views refer to where they now are (see _relocate()). One that hasn’t changed since it was copied is left alone (eg: the user’s changes to it are kept).

Parameters:

  • source (str | Traversable | None) – Where the plugins that come with the program are (by default, bundledFolder()).

  • target (str | None) – The plugins folder (by default, PLUGINS_FOLDER).

Returns:

The plugins copied (their folders’ names).

Return type:

list[str]

sn.plugins.STAMP = '.bundled'¶

The file, in an installed plugin’s folder, that says what it was copied from (see installBundled()): a hash of the bundled plugin’s files (see _contentHash()). One installed without it (eg: by an older version) is taken to have changed.
