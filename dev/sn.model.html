sn.model package¶

Defines and instantiates TopModel that must ALWAYS be memory resident for the program to work. Top model contains the following base objects:

  • top

    • node

      • collection

      • context

        • rule

        • definition

        • query

        • constraint

          • requirement

    • relation

      • isa

      • distinct

      • contains

        • antecedent

        • consequent

        • definiendum

        • definiens

        • condition

        • required

sn.model.NAME_NOTE = 'The name of the object. Can be used to access the object in the model.\n\nIn a pattern (a rule, query, definition or constraint) a variable stands for whatever matches: a name starting with "?" is an individual variable (it matches individuals), with "^" a type variable (it matches types), and with "!" an "any" variable (it matches individuals and types alike); any other name is a constant. A variable whose name starts with "_" after that (eg: "?_b") is hidden: it isn\'t reported in a query\'s answers. A variable\'s constraints -- what what it matches must be like -- are in its "constraints" attribute (see that attribute\'s note). They can also be typed here, after the name and ":where:", eg:\n  ?p :where: alive, age: 30\nand are then moved into that attribute.'¶

The note on the name attribute: shown as its tooltip in the attribute editor.
