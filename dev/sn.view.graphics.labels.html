sn.view.graphics.labels module¶

Label templates: what an object’s label says, as a string with shell-style (POSIX parameter expansion) substitutions:

$key or ${key} the value of key ${key:+text} text if key has a (non-empty) value, else nothing ${key:-text} key’s value, or text if it has none $$ a “$” \n a line break $(module:function) what a hook returns (see sn.hooks): eg: source code

text may itself contain substitutions, and key may be a hook’s call: ${(module:function):+text} is text if the hook returns something. Keys (see labelLookup()) are any attribute of the object (its effective value), and:

name its name localName its name only if it has its own (not one inherited) type the names of its types (parents), comma separated constraints a variable’s constraints (see sn.model.constraints) id its id

Eg: $name${constraints:+ {$constraints}} gives “fred” or “?p {alive}”; $type${name:+: $name} gives Sowa’s “person: fred”.

The template is the object’s “vis/label” attribute if it has one (eg: set on a type, for all its instances), else the “gui/label” preference (“gui/relationLabel” for relations). Tooltips are templates too: “vis/tooltip”, else “gui/tooltip” (see DEFAULT_TOOLTIP). A hook is called each time the template is expanded – for a label, each time it’s drawn – so a slow one is better in a tooltip.

The default label template, for nodes and relations alike.
