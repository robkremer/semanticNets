Keys and mouse¶

Every key shortcut and mouse gesture in Semantic Nets, in one place. (Help | Keys and Mouse opens this page.) On Windows and Linux, Cmd is Ctrl and Option is Alt, as the second column shows.

The keys in a view work while the mouse is over its drawing (the canvas takes the keyboard when the mouse comes into it); in the terminal pane, the usual text keys work instead.

Dialogs¶

  • Return (or Enter) presses the default button (eg: OK, Find, Save Changes), and Esc cancels or closes. Cmd-W (Ctrl+W) closes the find dialog and the source window too.

  • In the attribute editor, double-click an attribute to edit it; when it asks for a new attribute’s name, Return or Tab goes on to its value.

  • In the model directory (Window | Model Directory), double-click or Return opens what’s selected.

  • In a list of choices (eg: choosing a model), double-click chooses.

  • In the Python parser’s list of files, Delete (Backspace) takes the selected ones out.
